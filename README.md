# 3Q Team Building Lucky Draw

약 60명이 같은 링크에 접속해 4개의 경품 게임을 순서대로 진행하는 실시간 모바일 뽑기 사이트입니다.

## 게임 순서
1. 4등 — 오덴세 무드 조명 — 3명
2. 3등 — 천지연 20만원 식사권 — 1명
3. 2등 — 신세계 상품권 30만원권 — 1명
4. 1등 — 마샬 액톤4 (완전 신상!!) — 1명

## 동작
- 메인 화면: 행사 전체 경품 포스터
- 참가자는 방 코드/초대 링크로 입장하고 이름 등록
- 각 게임 시작 전 해당 경품 이미지 공개
- 진행자가 `3 · 2 · 1` 시작
- 현재 추첨 대상자 수만큼 카드 생성
- 게임마다 당첨 카드 위치를 서버에서 무작위 배치
- 한 카드는 한 명만 선택 가능
- 추첨 대상자가 모두 선택하면 결과 자동 공개
- 당첨자는 다음 게임부터 추첨 대상에서 제외되고 **관전 모드**로 전환
- 한 번 당첨된 사람은 이후 게임에서 카드 선택 및 재당첨 불가
- 관전자도 상품 화면, 카운트다운, 진행 현황, 결과를 실시간으로 함께 봄
- 진행자는 전원이 선택하지 않아도 **현재 선택자만으로 당첨 결과 공개** 가능
- 강제 결과 공개 시 미선택자는 해당 게임에서 제외되며, 선택 완료 카드 안에서 필요한 당첨 인원을 무작위로 확정
- 결과 공개 시 모든 참가자에게 당첨자 이름 표시
- 실제 당첨자 화면에는 축하 메시지와 폭죽 애니메이션 표시
- 진행자 화면에서도 결과 공개 시 폭죽 표시
- 마지막 1등 당첨자 공개 후 5초 동안 발표 화면 유지
- 5초 뒤 진행자·참가자·관전자 화면에 큰 **수고하셨습니다.** 문구와 1~4등 전체 최종 당첨 결과 자동 표시
- 최종 화면에서 새로고침하거나 다시 입장해도 전체 결과 표시 (서버가 실행 중인 동안)
- 첫 게임 시작 시 참가 명단 고정

## 진행자의 조기 결과 공개
`현재 선택자만으로 당첨 결과 공개 →` 버튼은 뽑기 진행 중에 표시됩니다.

- 최소한 해당 게임의 당첨 인원수만큼은 카드 선택이 완료되어야 합니다.
- 이미 선택된 원래 당첨 카드가 있으면 그대로 유지합니다.
- 아직 선택되지 않은 당첨 카드 자리는 선택 완료 카드 중에서 다시 무작위로 확정합니다.
- 따라서 조기 종료하더라도 4등은 3명, 나머지 게임은 1명의 당첨자가 반드시 확정됩니다.

## 로컬 실행
```bash
npm install
npm start
```
브라우저에서 `http://localhost:3000` 접속.

## Render 배포
- Runtime: Node
- Build command: `npm install`
- Start command: `npm start`
- Node.js: 20 이상

`render.yaml`이 포함되어 있어 GitHub 저장소에 올린 뒤 Render Web Service로 연결할 수 있습니다.

## 주의
현재 방 상태는 서버 메모리에 저장됩니다. Render 서버가 재시작되면 진행 중인 방은 사라집니다. 행사 당일에는 추첨 직전에 방을 만들어 사용하는 것을 권장합니다.
